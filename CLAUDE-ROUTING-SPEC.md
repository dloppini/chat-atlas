# Claude routing requirements

- Support concurrent chats across projects in one VS Code window, with no reload, restart, workspace reordering, or interruption of other chats.
- Leave Claude's installed files unchanged. The user now accepts native editor tabs; retain Claude's own controls and authentication.
- Remove the 0.1.20 reload workaround and pending startup handoff. Retain the corrected sixth routing argument for the native sidebar.
- New cross-project chats open a fresh native sidebar composer with an editable project instruction and space for the task. Only the user submits it. Keep matching-workspace chats blank. Use the sidebar prompt argument introduced in 2.1.330 and the older prompt-bearing open command for earlier builds. File a recognized first-message instruction under its known board project and derive the fallback title from the user's task. Preserve Claude's recorded cwd and UUID for resume.
- Cross-project resume opens Claude's native editor command with an explicit column. A serialized, one-shot directory bridge redirects only Claude's panel-construction realpath call in the current async context. Restore the filesystem function immediately on interception and in finally. Never redirect unrelated filesystem operations.
- Keep the board visible when resuming a different project's chat. Reuse a separate Claude editor group, or open beside the board. The sidebar prompt guides file work while the session remains rooted in the workspace.
- Gate the bridge on verified Windows version/bundle fingerprint pairs. Retain older verified builds when adding new ones, and test each available build's directory resolution. Unknown builds fail before opening a tab. Replace the bridge when Anthropic exposes a cwd argument. No project hooks, transcript copies, replacement UI, auth handling, or persistent Claude modifications.
- Resume uses the original UUID. Native Claude reuses an open session. Closed chats are retrieved from the Atlas history index. A sidebar draft becomes a board card after the user sends a message and Claude writes the history.
- Preserve Codex routing, the Git dashboard, explicit terminal actions, and board restoration.
- Test isolation, restoration on failure, unsupported builds, invalid directories/IDs, parallel requests and native reuse. In isolated VS Code, verify the sidebar draft on first open with the default editor preference, append a task, and check that the workspace and transcript count stay stable. Verify resume against the recorded directory and UUID.
